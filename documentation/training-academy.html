Register New Attendee

Add attendees on-the-fly if they weren't pre-registered:

Step 1: Fill in attendee details
Name: (Required) - at least 2 characters Email: (Required) - must be valid email Phone: (Optional) - in format: +255700000000 Category: (Optional) - Youth/Speaker/Business/Staff

✓ Success! System shows ID and QR code

Check-in Process

When attendee arrives at the event:

1. Scan QR Code or manually enter Attendee ID in the scan field
2. Enter Staff Name (who is checking them in)
3. Click "✅ CHECK IN"
✓ System records exact check-in time and staff name

Check-out Process

When attendee leaves the event:

1. Scan QR Code or enter Attendee ID
2. Enter Staff Name (who is checking them out)
3. Click "❌ CHECK OUT"
✓ System records exact check-out time

Status Indicators

✓ In Event Green Badge Currently at the event

7. Troubleshooting

Common Issues & Solutions

❌ "Email already registered"

Problem: Cannot register attendee with that email Solution:
  • Check if attendee already exists in system
  • Use a different email address
  • Contact admin if attendee needs account reset

❌ "Attendee not found"

Problem: Cannot find attendee during check-in Solution:
  • Verify QR code is correct
  • Check attendee ID number
  • Register attendee on-the-fly if needed
  • Check spelling of name

❌ "Already checked in"

Problem: Cannot check in attendee twice Solution:
  • This is a safety feature - prevents duplicate check-ins
  • Check out the attendee first if re-entry needed
  • Contact admin if there's an error

❌ "Database connection failed"

Problem: System cannot reach database Solution:
  • Check internet connection
  • Wait 30 seconds and retry
  • Refresh the page
  • Contact IT support if persists

Dashboard Not Loading

Solution Steps:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Close browser completely
  3. Reopen and navigate to http://localhost:3000
  4. If still not working, check Docker containers are running

8. Frequently Asked Questions

❓ Can I register attendees before the event?
Yes! You can register attendees in advance through pre-registration. This creates their records and generates QR codes. At the event, you just scan and check them in.
❓ What if an attendee loses their badge?
You can regenerate badges anytime. Go to Badge Generator, select the attendee, and download a new badge. Print it and give it to them.
❓ Can multiple staff members check in at once?
Yes! Each staff member can use their own device. The system handles concurrent check-ins and logs who checked in each attendee.
❓ What if the QR scanner doesn't work?
You can manually type the Attendee ID instead. Just enter the ID number in the scan field and check in. The system accepts both.
❓ Are check-in times recorded accurately?
Yes! Every check-in and check-out records the exact time to the second. This is useful for analytics and reporting.
❓ Can I print badges on regular paper?
Yes, use the HTML format badges. They print on regular paper. For professional badges, print on badge stock (3.5" x 2.2").
❓ What categories of attendees are supported?
Default categories: Youth, Speaker, Business Leader, Staff. Custom categories can be added by admins.
❓ How often does the dashboard update?
The dashboard automatically refreshes every 5 seconds with the latest data. No manual refresh needed.
❓ Can I export attendance reports?
Yes! The Statistics tab shows detailed attendance tables that can be copied and pasted into Excel or printed.
❓ Is my data secure?
Yes! The system uses role-based access control, encrypted connections, and complete audit logging. Only authorized staff can access attendee data.
