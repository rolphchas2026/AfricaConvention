8. Troubleshooting Guide

Common Issues & Solutions

❌ "Email already registered"

Problem: Cannot register attendee
Solutions:
  • Check if attendee already exists in system
  • Use different email address
  • Contact admin for account issues

❌ "Attendee not found"

Problem: Cannot find attendee during check-in
Solutions:
  • Verify QR code is correct
  • Check attendee ID number
  • Register attendee on-the-fly if needed
  • Check spelling if entering manually

❌ "Already checked in"

Problem: Cannot check in attendee twice
Solution:

This is by design - prevents duplicate check-ins. Check out the attendee first if re-entry is needed.

❌ "Database connection failed"

Problem: System cannot reach database
Solutions:
  • Check internet connection
  • Wait 30 seconds and retry
  • Refresh the page
  • Check if Docker containers are running
  • Contact IT support

❌ Dashboard Not Loading

Solutions:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Close browser completely
  3. Reopen and go to http://localhost:3000
  4. Check Docker containers are running
QR Scanner Not Working: You can always type the Attendee ID manually in the scan field

9. Frequently Asked Questions

❓ Can we register attendees before the event?
Yes! Pre-register attendees to create records and generate QR codes. At the event, simply scan and check them in. This is the recommended approach.
❓ What if an attendee loses their badge?
Go to Badge Generator, select that attendee, and generate a new badge. Print and give it to them. You can regenerate anytime.
❓ Can multiple staff members use the system simultaneously?
Yes! Multiple devices can check in at the same time. The system is designed for concurrent use and tracks who checked in each person.
❓ What if the QR scanner doesn't work?
Simply type the Attendee ID manually in the scan field. The system accepts both QR scans and manual ID entry.
❓ Are times recorded accurately?
Yes! Every check-in and check-out records the exact time to the second. This provides accurate attendance analytics.
❓ Can badges be printed on regular paper?
Yes! Use HTML format for regular paper printing. For professional badges, use badge card stock (3.5" × 2.2").
❓ What categories can we use?
Default categories: Youth, Speaker, Business, Staff. Custom categories can be added by system administrators if needed.
❓ How often does the dashboard refresh?
The dashboard automatically refreshes every 5 seconds. No manual refresh needed.
❓ Can we export attendance reports?
Yes! The Statistics tab shows all data that can be copied to Excel, printed, or screenshotted for reporting.
❓ Is our data secure?
Yes. The system uses role-based access control, data validation, and complete audit logging for security.
